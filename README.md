# MacDictator

Диктовка для macOS. Нажимаете правый Cmd, говорите, нажимаете ещё раз — текст появляется там, где стоит курсор. Речь распознаётся прямо на вашем маке через MLX Whisper, интернет не нужен и никуда ничего не отправляется.

Опционально — чистка текста от слов-паразитов и перевод через DeepSeek или OpenAI, транскрибация готовых аудиозаписей с разделением собеседников по каналам.

### [⬇ Скачать последнюю версию](https://github.com/OlegArapov/MacDictator/releases/latest)

**Нужен Mac на Apple Silicon (M1, M2, M3, M4) и macOS 14 или новее.** На маках с процессором Intel приложение не запустится: распознавание идёт на Apple GPU. Проверить: меню  → About This Mac, в строке Chip должно быть Apple M1 или новее.

## Установка

Ничего клонировать и устанавливать через терминал не нужно: Python, библиотеки и всё остальное уже лежат внутри `.dmg`. Одна команда в терминале всё же понадобится — на шаге 3.

**1. Разрешить установку сторонних приложений.** System Settings → Privacy & Security → пролистайте до «Разрешить использование приложений из» и выберите **«App Store и от известных разработчиков»**. Если оставить «App Store», macOS заблокирует установку наглухо и даже не покажет кнопку разрешения на шаге 4.

**2. Установить приложение.** Скачайте `MacDictator-<версия>.dmg` со [страницы релиза](https://github.com/OlegArapov/MacDictator/releases/latest) (раздел **Assets** внизу) и откройте его. В открывшемся окне перетащите иконку **MacDictator** в папку **Applications**. Запускать приложение прямо из окна образа нельзя — оно не заработает. После установки образ извлеките: в боковой панели Finder, в разделе «Места», нажмите ⏏ рядом с `MacDictator`.

**3. Снять карантин.** Приложение не заверено в Apple, поэтому macOS считает его повреждённым. Откройте Терминал (⌘+Пробел, набрать «Терминал») и вставьте команду:

```bash
xattr -cr /Applications/MacDictator.app
```

Нажмите Enter. Ответа не будет — так и должно быть.

**4. Разрешить запуск.** Запустите MacDictator из Launchpad, macOS сообщит, что разработчик не подтверждён:

- **macOS 15 Sequoia и новее:** System Settings → Privacy & Security → пролистайте вниз до сообщения про MacDictator → **Open Anyway** → подтвердите. Правый клик → Open в Sequoia больше не работает.
- **macOS 14:** правый клик по иконке в Applications → **Open** → в диалоге ещё раз **Open**.

**5. Выдать два разрешения.** Без них не сработают ни горячая клавиша, ни вставка текста:

- System Settings → Privacy & Security → **Input Monitoring** → `+` → выберите `/Applications/MacDictator.app` → включите переключатель
- System Settings → Privacy & Security → **Accessibility** → `+` → то же приложение → включите переключатель

**6. Перезапустить приложение.** Разрешения применяются только после перезапуска.

**7. Скачать языковую модель.** Сама по себе она не скачается. В окне MacDictator нажмите **«API Keys & Prompts»** внизу слева — откроется окно Setup. В блоке **MLX Whisper** нажмите **Download model** и дождитесь, пока статус сменится на **Ready**. Модель `turbo` весит около 1,5 ГБ, `large-v3` — около 3 ГБ, лежат в `~/.cache/huggingface/`. Дальше приложение работает локально и без интернета.

**8. Проверить, куда пойдёт текст.** В настройках параметр **Send** должен стоять в **Paste** — тогда распознанное вставится в активное окно. При `Off` текст никуда не попадёт, и будет казаться, что приложение не работает.

Обновления приложение проверяет само и показывает на плашке, когда выходит новая версия.

## Как пользоваться

| Клавиша | Действие |
|---|---|
| **Правый Cmd** | Начать и остановить запись |
| **Ctrl+Shift+Space** | То же самое, если правый Cmd занят |
| **Esc** | Отменить запись без распознавания |

После остановки записи текст вставляется в активное окно сам. На плашке есть две кнопки: **📁** — распознать готовый аудиофайл (mp3, wav, flac, ogg, aiff; результат ляжет в `.txt` рядом с файлом и в буфер обмена), **⚙** — настройки.

Для записей звонков в настройках есть тумблер **Split**: левый канал станет репликами «Я», правый — «Собеседник», диалог соберётся по очереди. Для длинных записей есть пресеты «Встреча» и «Интервью» с автоматическим саммари.

## Настройки

- **Engine** — `MLX` (локально, по умолчанию) или OpenAI API
- **Model** — `large-v3` точнее, `turbo` быстрее
- **Cleanup** — `Off` / `Lite` (убрать паразитов) / `Medium` (правка грамматики) / `Max` (переписать как связный текст)
- **Cleanup model / Translate model** — `DeepSeek` или `OpenAI`
- **Translate** — `Off` или язык перевода
- **Send** — `Paste` (вставлять сразу), `Copy` (только в буфер) или `Off`
- **Mic** — выбор микрофона

Чистка и перевод работают через внешние LLM и требуют API-ключа — вводится в настройках. Само распознавание речи ключей не требует и наружу ничего не отправляет.

- OpenAI: https://platform.openai.com/api-keys
- DeepSeek: https://platform.deepseek.com/api_keys

## Если что-то не работает

- **Плашка не появляется по правому Cmd** — не выдан Input Monitoring (шаг 5), после выдачи приложение надо перезапустить
- **Текст распознался, но не вставился** — не выдан Accessibility (шаг 5) либо `Send` стоит в `Off` (шаг 8)
- **«Программа повреждена и не может быть открыта»** — пропущен шаг 3 с `xattr`
- **«Не удаётся открыть программу»** — приложение запускают прямо из окна образа (шаг 2) либо в настройках стоит «только App Store» (шаг 1)
- **В Privacy & Security нет кнопки «Открыть всё равно»** — она не появляется, пока не выполнен шаг 1
- **`Model not downloaded. Open Setup`** — не скачана модель, шаг 7
- **`Unable to load kernel …` от metal::Device** — сборка новее вашей macOS; нужна версия 1.0.11 или новее
- **Приложение не открывается вообще** — проверьте, что мак на Apple Silicon и macOS не старше 14

## Для разработчиков

Запуск из исходников. Нужен Python 3.10+, рекомендую 3.12 через Homebrew (`brew install python@3.12`).

```bash
git clone https://github.com/OlegArapov/MacDictator.git
cd MacDictator

python3.12 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

Установка зависимостей занимает пару минут — `torch`, `mlx` и `numpy` тяжёлые. Запуск: двойной клик по `scripts/MacDictator.command` в Finder (скрипт сам проверит venv и доустановит зависимости) либо `venv/bin/python app.py`.

При запуске из исходников разрешения Input Monitoring и Accessibility выдаются не приложению, а терминалу (Terminal.app или iTerm) — именно он запускает Python.

Venv привязан к абсолютному пути: после переноса папки проекта его надо пересоздать (`rm -rf venv` и заново), модель в `~/.cache/huggingface/` при этом не теряется.

### Тесты и сборка

```bash
venv/bin/python -m pytest tests/ -q   # 43 теста
./scripts/build.sh                    # dist/MacDictator.app + DMG в корне
```

`build.sh` собирает `.app` через py2app, докладывает в бандл скрипты Tcl/Tk, переподписывает бинарники и упаковывает DMG. Запускать можно из любой папки — скрипт сам переходит в корень проекта. Иконка `assets/MacDictator.icns` лежит в репозитории, перегенерировать из PNG можно через `venv/bin/python assets/make_icon.py`.

Подпись берётся из сертификата `MacDictator Dev` в keychain (переопределяется переменной `MACDICTATOR_SIGN_ID`). Это важно: при ad-hoc подписи CDHash меняется с каждой сборкой, и macOS сбрасывает выданное разрешение Accessibility при каждом обновлении. Со стабильной идентити разрешение выдаётся один раз.

### Структура

```
app.py            приложение: UI, запись, распознавание, обработка через LLM
prompts.json      системные промпты для чистки и перевода
setup.py          конфигурация py2app
macdictator/      file_transcribe — файлы, каналы, пресеты
                  progress — процент и ETA
                  multiscreen — геометрия индикаторов на нескольких мониторах
                  tray — иконка в менюбаре
assets/           иконки и генератор make_icon.py
scripts/          build.sh, MacDictator.command
tests/            pytest
```

Настройки и история лежат рядом с `app.py` при запуске из исходников и в `~/Library/Application Support/MacDictator/` в собранном приложении. `keys.json`, `settings.json` и `history.json` в `.gitignore` и в репозиторий не попадают.
